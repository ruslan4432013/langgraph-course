# Сервер MCP

Разработан на [официальном sdk](https://gofastmcp.com/getting-started/welcome). Продемонстрированы только основные возможности
сервера в соответствие с протоколом MCP.

## Структура проекта

./scripts - скрипты для запуска проекта;

./src/main.py - точка входа запуск проекта;

./src/server.py - конфигурации сервера;

./src/primitive/ - инструменты, ресурсы и промпты

## Запуск

Склонировать проект, перейти в корневую директорию, выполнить команду:

```
./scripts/linux.sh

или

./scripts/windows.bat
```
