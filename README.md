# MCP-сервер (ToDo-список)

MCP-сервер разработан с использованием [официального SDK](https://gofastmcp.com/) и демонстрирует расширенные возможности сервера в соответствии с MCP-протоколом: логирование, эликитация, сэмплирование.

## Структура проекта

| Путь | Описание |
|---|---|
| `./scripts` | Скрипты для запуска проекта |
| `./src/main.py` | Точка входа |
| `./src/server.py` | Конфигурация сервера |
| `./src/primitive/` | Tools, Resources и Prompts |
| `./src/service/` | Бизнес-логика (ToDoList) |

## Что добавлено в этом уроке

- **Логирование** — `ctx.info()`, `ctx.warning()`, `ctx.debug()`, `ctx.error()` в инструментах
- **Эликитация** — `ctx.elicit()` для подтверждения создания списка + форма с Pydantic-моделью (`add_detailed_task`)
- **Сэмплирование** — `ctx.sample()` для генерации задач с помощью LLM клиента (`generate_tasks`)

## Запуск

1. Клонируйте репозиторий и перейдите в корень проекта
2. Выполните скрипт запуска:

```bash
# Linux / macOS
./scripts/linux.sh

# Windows
scripts\windows.bat
```

Сервер запустится на `http://localhost:8000/mcp`.
