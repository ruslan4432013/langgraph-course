# Курс по LangGraph: Подграфы (Subgraphs)

Данный проект является учебным пособием по работе с подграфами в LangGraph. Здесь собраны примеры реализации различных
паттернов использования подграфов, управления их состоянием и интеграции в общую архитектуру приложения.

## Структура проекта

* `src/examples/` — основные примеры кода:
    * `as_node/` — примеры использования скомпилированных графов напрямую как узлов родительского графа.
    * `from_node/` — примеры вызова подграфов из функций-узлов с трансформацией состояния.
    * `subgraph_state.py` — пример управления состоянием подграфа.
    * `subgraph_stream.py` — пример стриминга обновлений из подграфов.
    * `persistance.py` — пример использования Checkpointer для сохранения состояния графа с подграфами.
* `langgraph.json` — конфигурационный файл для запуска и визуализации графов в LangGraph Studio.
* `requirements.txt` — список необходимых зависимостей.
* `src/settings.py` — конфигурация настроек через Pydantic.
* `assets/` — вспомогательные материалы (изображения).

## Установка

1. Клонируйте репозиторий.
2. Создайте виртуальное окружение и активируйте его.
3. Установите зависимости:

```bash
pip install -r requirements.txt
```

4. Создайте файл `.env` в корневом каталоге и добавьте необходимые ключи (см. `src/settings.py`):

```env
OPENAI_API_KEY=your_openai_api_key
LANGSMITH_TRACING=true
LANGSMITH_ENDPOINT="https://api.smith.langchain.com"
LANGSMITH_API_KEY=your_langsmith_api_key
LANGSMITH_PROJECT=your_project_name
```

## Использование

### Запуск примеров

Вы можете запустить любой пример напрямую через Python:

```bash
python src/examples/as_node/01_simple_graph.py
```

### LangGraph Studio

Проект полностью настроен для работы с [LangGraph Studio](https://github.com/langchain-ai/langgraph-studio). В файле
`langgraph.json` описаны доступные графы:

* `simple_graph`
* `shared_state_schema`
* `first_subgraph`
* `subgraphs`
* `different_state_schema`
* `two_levels_subgraph`
* `persistence`
* `subgraph_state`
* `subgraph_stream`

Просто откройте папку проекта в LangGraph Studio, чтобы визуализировать и протестировать каждый из них.

## Основные концепции

В материалах рассматриваются:

1. **Подграф как узел**: Простейший способ вложить один граф в другой.
2. **Трансформация состояния**: Передача данных между родительским графом и подграфом при различии их схем (TypedDict).
3. **Многоуровневые подграфы**: Создание иерархических структур произвольной вложенности.
4. **Стриминг (`subgraphs=True`)**: Получение обновлений от узлов подграфов в режиме реального времени.
5. **Персистентность**: Использование чекпоинтов для сохранения состояния всей иерархии графов.
