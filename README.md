# AI-приложение с клиентом MCP

Клиент создан на стеке Python 3.11 / LangChain / LangGraph в учебных целях. Работает в тандеме с [MCP-сервером](../server/).

ReAct-агент, способный вызывать серверные ресурсы, инструменты и промпты для управления списками дел. Поддерживает логирование и эликитацию через Callbacks. Для сэмплирования используется отдельный FastMCP Client (`sampling_client.py`).

## Структура проекта

| Путь | Описание |
|---|---|
| `./scripts` | Скрипты для запуска проекта |
| `./src/agent.py` | Агент с бизнес-логикой + Callbacks |
| `./src/sampling_client.py` | FastMCP Client для сэмплирования |
| `./src/settings.py` | Загрузка конфигурации |
| `./.env` | Файл конфигурации |
| `./langgraph.json` | Конфигурация LangSmith |

## Перед запуском

1. Заполненный файл `.env` (создайте из `.env.example`)
2. Установленный Python 3.11
3. Запущенный MCP-сервер (из папки `server/`)

## Запуск

Клонируйте проект, перейдите в корень и выполните:

```bash
# Linux / macOS
./scripts/linux.sh

# Windows
scripts\windows.bat
```

### Запуск клиента сэмплирования

```bash
# После активации виртуального окружения
python -m src.sampling_client
```
